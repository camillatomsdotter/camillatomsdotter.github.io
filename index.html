Introduktion

Så fungerar Claude Code

Claude Code är ett AI-verktyg från Anthropic som hjälper dig att skriva och ändra kod. Du beskriver vad du vill ha med vanliga ord – Claude läser ditt projekt, gör ändringarna och kontrollerar att de fungerar.

Vad är Claude Code?

Till skillnad från en vanlig chatt, där du kopierar kod fram och tillbaka, arbetar Claude Code direkt i ditt projekt. Det är en så kallad agent: den kan själv läsa filer, redigera dem, köra kommandon och använda dina utvecklingsverktyg för att lösa en uppgift från början till slut.

Hur det fungerar – steg för steg

  1. Du beskriver uppgiften

    Till exempel: ”Lägg till ett kontaktformulär på startsidan” eller ”Varför kraschar appen när jag loggar in?”

  2. Claude läser in sig

    Claude tittar igenom de filer som är relevanta för att förstå hur projektet hänger ihop.

  3. Claude planerar och gör ändringar

    Koden skrivs eller ändras – ofta i flera filer samtidigt.

  4. Claude testar

    Kommandon och tester körs för att kontrollera att ändringen faktiskt fungerar, och fel rättas.

  5. Du granskar och godkänner

    Du ser vad som ändrats och bestämmer själv. Claude kan också skriva ett commit-meddelande och skapa en pull request i git.

Vad kan man använda det till?

Bygga nya funktioner

Beskriv vad du vill ha, så planerar och skriver Claude koden.

Hitta och rätta buggar

Klistra in ett felmeddelande så spårar Claude orsaken och föreslår en lösning.

Tråkiga rutinjobb

Skriva tester, uppdatera beroenden, lösa merge-konflikter och skriva release notes.

Arbeta med git

Skapa brancher, skriva commit-meddelanden och öppna pull requests.

Koppla in andra verktyg

Via MCP kan Claude till exempel läsa dokument eller uppdatera ärenden i andra system.

Egna instruktioner

En fil som heter CLAUDE.md berättar för Claude vilka regler och vanor som gäller i ditt projekt.

Var kan man använda det?

Claude Code finns på flera ställen, och alla använder samma motor:

Terminalen

Den mest kompletta versionen, styrd med text-kommandon.

Kodredigerare

Tillägg för VS Code, Cursor och JetBrains-program.

Desktop-appen

I Claude-appen för Mac och Windows, under fliken Code.

Webben & mobilen

Direkt i webbläsaren på claude.ai/code – utan installation.

Kom igång i terminalen

På Mac eller Linux installerar du Claude Code genom att öppna terminalen och köra:

curl -fsSL https://claude.ai/install.sh | bash

På Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Gå sedan till en projektmapp och starta Claude:

cd mitt-projekt
claude

Första gången blir du ombedd att logga in. De flesta varianter kräver ett Claude-abonnemang eller ett konto i Anthropic Console. Installationsanvisningar kan ändras – kontrollera alltid den officiella dokumentationen.
